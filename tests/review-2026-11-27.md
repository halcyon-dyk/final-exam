# 전체 게임 점검 — 2026-11-27

## 후속 수정: 1~3번 (2026-11-27)

- 일시정지·도움말에서 리사이즈하면 동일 메뉴와 정지 상태를 복원한다. 계속하기 이후에는 타이머가 재개되며 닫은 메뉴가 다시 나타나지 않는다.
- 전선 영역을 세로 28~72%, 시설 지도 영역을 74~98%로 분리했다. 기존 중첩 좌표에서 전선 퍼즐, 지도 중앙에서 시설 지도가 각각 열린다.
- 조합 시 보관함을 열고 제목에 ‘조합: 다른 도구 선택’을 표시한다. 입력을 가리는 안내창 없이 두 번째 도구를 선택하며 조합 후 제목을 복원한다.
- `--audit`는 이제 세 수정 사항을 검증하는 회귀 검사다. 실제 좌표 클릭 및 반복 리사이즈를 960/320/390px에서 통과했다. 아래 최초 발견 기록의 4~5번은 이번 수정 범위에 포함하지 않았다.

## 최초 점검 기록

후속 수정 4~5번: 힌트와 명세의 단서 위치를 ‘벽 낙서와 바닥 쪽지’로 통일했다. 보관함은 PC 48px 행, 모바일 64px 칸 전체가 선택되며 모바일 세 아이템을 한 줄로 배치한다. 모바일 선택 상태는 글자색과 바탕색으로 구분한다. 960/320/390px에서 영역 크기·겹침·패널 경계 및 글자 바깥쪽 클릭 조합을 검사했다.

게임 코드는 수정하지 않았다. 별도 임시 Chrome 프로필로 검사했고 실사용 저장은 변경하지 않았다.

## 재현한 문제

1. **일시정지 중 리사이즈하면 정지가 풀림 (우선 수정).** 일시정지 → 창 너비 변경 → 메뉴가 사라지고 `pausedForMenu`가 false로 바뀐다. `js/ui/Layout.js:34`의 장면 재시작과 `js/scenes/GameScene.js:32`의 초기화가 원인이다. 정지 상태와 메뉴를 복원해야 한다.
2. **통제실 전선·시설 지도 클릭 영역 겹침.** 방 영역의 가로 55%, 세로 68% 위치에서 실제 캔버스 클릭 시 시설 지도가 열린다. 이 좌표는 전선과 지도 양쪽에 포함된다(`js/rooms/ControlRoom.js:13`, `:15`). 전선은 가로 35~75%/세로 28~76%, 지도는 가로 49~91%/세로 58~98%다. 배경의 사물 윤곽에 맞춰 클릭 영역을 분리하는 것이 좋다.
3. **조합 안내가 다음 아이템 선택을 막음.** 손전등 본체 선택 → 조합 → 배터리 클릭 시 안내창의 입력 차단막 때문에 선택되지 않는다. 닫기를 누른 다음 배터리를 선택하면 조합은 가능하다. `js/scenes/GameScene.js:139`의 모달 안내를 비차단 안내로 바꾸거나 닫고 선택하라는 설명이 필요하다.
4. **힌트와 사물 위치 표현 불일치.** `js/ui/HintPanel.js:38`은 ‘침대 아래’를 안내하지만 조사 대상은 ‘바닥 쪽지’다. spec.md의 단서 위치도 같은 구문이므로 실제 배경에 맞춰 함께 정리해야 한다.
5. **보관함 터치 영역이 작음.** 아이템은 높이 22px인 글자만 클릭 가능하다. 일반 버튼의 44px에 비해 모바일에서 누르기 어렵다(`js/ui/InventoryPanel.js:62`). 아이템 행 단위로 터치 영역을 늘리는 것이 좋다.

1~3은 Chrome 960/320/390px에서 재현했다. 4는 코드·명세 대조, 5는 실제 브라우저의 아이템 영역 측정 결과다. 2는 클릭 영역 중첩 재현이며 사물 윤곽 전체의 픽셀 단위 적합성까지 검증한 것은 아니다.

## 검사 방법과 범위

- `node tests/hints.cjs`, `migration.cjs`, `clue-state.cjs`, `regression.cjs`, `audio-settings.cjs`: 모두 통과.
- `node tests/power-browser.cjs --enhanced`: 960/320/390px 모두 통과. 전체 탈출, 4개 저장 시점에서 실제 새로고침·이어하기, 성공/실패 재시작, 힌트 점수와 설정 유지 검사.
- `node tests/power-browser.cjs`: 960/320/390px 모두 통과. 전력 8조합, 확인·닫기, 새 비상문 정답과 모바일 문서 배치 검사.
