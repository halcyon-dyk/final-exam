# 강화판 검증 (2026-11-26)

프로젝트 루트에서 Node로 실행한다. npm 설치·빌드는 필요 없다.

```powershell
node tests/hints.cjs
node tests/migration.cjs
node tests/clue-state.cjs
node tests/regression.cjs
node tests/audio-settings.cjs
node tests/power-browser.cjs
node tests/power-browser.cjs --enhanced
node tests/toolbox-browser.cjs
```

- 단위 검사: 7과제·21단계 힌트 공개, 무료 재열람·저장 복원, 구버전 저장 변환·발견한 문서만 교체·반복 로드, 잘못된 저장, 음향 설정.
- 전력 브라우저 검사: 960/320/390px, 8조합 오답 우선순위·확인/닫기·44px 조작 영역·새 비상문 정답과 문서 배치.
- 강화판 브라우저 검사: 사물/버튼 이벤트로 감금실부터 탈출까지 진행한다. 전력 입력 중/해결 후·비상문 입력 중/해결 후 실제 페이지 새로고침 4회와 이어하기, 모바일 이름표 겹침·리사이즈, 힌트 점수·일시정지·문서 열람 중 타이머, 성공/시간 초과 재시작·새 게임 확인·취소·설정 보존을 검사한다.
- 기존 브라우저 검사: 7개 PC/모바일 사례의 공구함·음향·상자/환풍구/비상문 배경 상태를 확인한다.
- 브라우저 검사는 설치된 Chrome과 Phaser CDN 네트워크 접속을 사용한다. 각 사례는 임시 프로필로 실행하므로 실제 플레이 저장을 읽거나 덮어쓰지 않는다. 실행 후 `tests/*.png`에 검사용 화면이 생성된다.
- `save-fixtures-browser.cjs`는 구버전 기준값을 만드는 도구다. 강화판 검증에는 실행하지 않는다. 보관한 `fixtures/saves-v1.json`은 `migration.cjs`에서 읽는다.

## Live Server에서 남은 수동 확인

1. 새 게임에서 설명 없이 문서만 보고 전력 배분과 사건 순서를 추론해 탈출한다(tasks.md 28번).
2. 힌트창 열기·페이지 이동·재열람은 무료이며, 공개 버튼만 횟수를 1회 늘리는지 확인한다.
3. 휴대폰에서 이름표·페이지 화살표·퍼즐 버튼의 실제 터치 감각과 글자 크기를 확인한다.
4. 원스토어 앱 실기기에서 SDK 시작·백그라운드 복귀·기기 무음·종료 후 이어하기를 별도 확인한다.

자동 검사의 버튼 이벤트 검증은 실제 터치 감각이나 설명 없는 사람의 추론 가능성 검증을 대신하지 않는다.
