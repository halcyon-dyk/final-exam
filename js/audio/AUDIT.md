# 음향 점검 — 2026-11-25

## 연결과 용도

- 감금실: 어두운 드론, 정비실: 차고 기계 환경음, 통제실: 컴퓨터실 환경음. 기존 출처 설명과 공간의 용도가 일치한다.
- 벽 낙서=연필, 쪽지/기록=종이, 상자=금속 두드림, 상자 해제=자물쇠, 환풍구=라쳇 드라이버.
- 정비실 본체/손전등=스위치, 볼트=너트, 벽=두드림, 공구함=금속/자물쇠.
- 통제실 전선=커넥터, 문서=종이, 전원 복구=전원 작동, 비상문=금속문 개방. 선택·오답·결과는 합성 조작/알림음.

## 확인과 변경

- Chrome AudioContext로 실제 로딩하는 14개 파일을 모두 해독했다. HTTP 오류나 전체 무음 파일은 없었다. 수치 기록: tests/audio-audit.json.
- 드라이버 2.5초, 볼트 1.8초, 벽 1.2초, 케이블 1.2초의 사용 구간을 유지한다. 볼트·벽·케이블 구간 무음 검사도 통과했다.
- 전원 복구 원본 RMS 0.2276으로 금속 두드림 0.0983보다 높아 기본 재생 계수를 0.4로 낮췄다. 음원 원본은 변경하지 않았다.
- 녹음 효과음은 재사용하며 같은 소리를 다시 누르면 기존 재생을 멈춘 뒤 시작한다. 드라이버도 동일하게 처리했다.
- 배경음 70%, 효과음 80% 기본 사용자 볼륨을 기존 음원별 계수에 곱한다. 각 채널 0% 및 전체 음소거를 지원한다.
- 배경 루프, 재생 중인 녹음, Web Audio 합성음 모두 설정에 반응하며 음소거 중에는 새 효과음을 시작하지 않는다.
- 실제 Chrome 오디오 객체에서 음소거/설정 복원과 320px·960px 설정창 경계·버튼 겹침 검사를 통과했다. 기존 방 진행/효과음 호출 회귀 검사도 통과했다.

점검 범위는 파일 해독·수치·출처에 기재된 녹음 용도·코드 연결 및 브라우저 동작이다. 실제 스피커/헤드폰으로 청취한 평가는 아니므로 최종 음색과 체감 균형은 Live Server에서 확인한다.
